# Security Policy

## Supported Versions

Only the latest release, or `main` in a repo that doesn't cut releases. A fix ships as the next release or merge.

## Reporting a Vulnerability

Please report vulnerabilities privately: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue for security problems.

Include what you found, where it lives (a file, a workflow, an image), and how to reproduce it.

What to expect:

- **Acknowledgement** within a few days. These are one-person projects, so response times are best effort.
- **Fix**: a confirmed vulnerability is fixed in the next release or merge.
- **Credit** in the advisory, unless you'd rather not.

## Scope

In scope: the repository's own code, configuration, images and CI workflows.

Out of scope: the third-party services, images and tools a repository uses. Report issues in those to their maintainers.

There is no bounty program. Reports are still appreciated.
